# GameZone – Registro e inicio de sesión

Página web de registro e inicio de sesión con validaciones del lado del cliente, hecha en HTML, CSS y JavaScript para Duoc UC (2025).

## Qué hace

- Alterna entre las pestañas de inicio de sesión y registro.
- Valida el formulario de registro: correo institucional, contraseña de al menos 10 caracteres, confirmación de contraseña y género favorito.
- Valida el inicio de sesión contra los usuarios registrados en la sesión.

Los usuarios se guardan en memoria, así que se pierden al recargar la página: es una maqueta de front-end sin backend.

## Cómo verlo

Abre `index.html` en el navegador.
